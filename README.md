# Mizan

Mizan is a governed AI experimentation platform. This milestone establishes its local application foundation: a React control plane, FastAPI API, and local SQLite database support.

## Stack

- React, Vite, TypeScript, Tailwind CSS, React Router, TanStack Query
- Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PyMySQL
- SQLite locally; MySQL/MariaDB-compatible production configuration

See [local setup](docs/development/LOCAL_SETUP.md), the [production deployment runbook](docs/deployment/PRODUCTION_RUNBOOK.md), and [project status](docs/PROJECT_STATUS.md).
