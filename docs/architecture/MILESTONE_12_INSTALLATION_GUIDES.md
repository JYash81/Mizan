# Milestone 12 — Installation Snippets & Integration Guides Architecture

## 1. Overview and Core Philosophy

In enterprise environments, copying and pasting unverified shell scripts or dynamic Python commands poses critical security hazards. Attackers can leverage installation instructions for command injection, credential harvesting, or supply-chain poisoning.

Mizan enforces strict security standards for all installation and integration snippets provided in the Model Zoo and App Zoo:

1. **Static and Deterministic**: Snippets are generated via pure deterministic templates parameterized exclusively by public listing metadata and cryptographic digests.
2. **Strictly Version-Pinned**: Every snippet explicitly pins the exact `version_tag` and 64-character SHA-256 `release_manifest_digest`. Generic `"latest"` tags are strictly forbidden.
3. **Zero Secrets**: Snippets NEVER contain API keys, session tokens, database passwords, or private tenant credentials. Placeholders (`<YOUR_API_TOKEN>`) are strictly enforced.
4. **Zero Execution**: The platform never executes snippets or runs subprocesses during snippet generation or viewing.
5. **Clear Pre-M13 Boundary**: Snippets clearly distinguish between client-side execution (e.g. local Python / CLI) and future managed runtime serving (Milestone 13).

## 2. Supported Formats & Code Generators

The `InstallationGuideService` provides standardized templates for multiple integration modalities:

### A. Python (Hugging Face Transformers / PEFT)
Pinned to the exact base model key and M11 adapter release digest:

```python
# Mizan Governed Installation Specification
# Release: Customer Support Assistant (v1.0.0)
# Manifest Digest: a1b2c3d4e5f60000000000000000000000000000000000000000000000000001
# Generated by Mizan Enterprise Model Zoo

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

base_model_key = "meta-llama/Llama-3-8B-Instruct"
adapter_path = "mizan-models/customer-support-assistant/v1.0.0"

tokenizer = AutoTokenizer.from_pretrained(base_model_key)
base_model = AutoModelForCausalLM.from_pretrained(
    base_model_key,
    torch_dtype=torch.float16,
    device_map="auto"
)
model = PeftModel.from_pretrained(base_model, adapter_path)
model.eval()
```

### B. Llama.cpp CLI
For quantized GGUF weights or local edge deployment:

```bash
# Mizan Governed Llama.cpp Command Line Specification
# Release: Customer Support Assistant (v1.0.0)
# Minimum RAM Required: 8.0 GB

llama-cli \
  --model ./models/meta-llama-3-8b.gguf \
  --lora ./models/customer-support-assistant-v1.0.0.bin \
  --threads 8 \
  --ctx-size 4096 \
  --temp 0.7 \
  --prompt "System: You are an approved Mizan assistant."
```
